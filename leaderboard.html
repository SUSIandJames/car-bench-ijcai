Held-out winner: Gemma4 (local, $0) at 0.583 beats baseline Gemini 0.333 on the very same 12 unseen tasks — and generalizes far better: seen→unseen drop is only −0.15 (.733→.583) vs Gemini's −0.47 (.80→.333). (Still n=12 — directional, not significant; a full 125-task run would confirm.)

Findings. (1) Unseen tasks are far harder: ~0.33 vs 0.80 on the first-20 set — our headline 0.80 is partly task-selection-dependent / optimistic; real held-out reliability is much lower. (2) Removing the planning tool (C) matched baseline Pass^3 at ~HALF the LLM calls (254 vs 525) and half the wall time, with 0 planning errors (vs 204/222) — the planning tool is pure cost here, no reliability benefit, so dropping it is a clean efficiency win. (3) Code-verify (B) did not help (nominally lower, more expensive) — consistent with an already-tuned agent.

⚠ n=12 Tiny sample: each split is n=4, so per-split Pass^3 moves in 0.25 steps and the A/C-vs-B gap is within noise — NOT statistically significant. Robust conclusions: only (1) unseen ≫ harder, and (2) planning-suppression halves cost without hurting Pass^3. A larger held-out run is needed to rank A vs C on reliability.

!  Caveats — read before celebrating

  • Sample size. Our latest row is computed on 60 tasks (20 base / 20 hallucination / 20 disambiguation), 3 trials each. The official baselines are computed on the full public test split of 254 tasks (100 / 98 / 56), 3 trials each. With n = 20 per split, the 95% confidence interval on each per-split Pass^3 is roughly ±0.15 (Wilson). The drop from 0.867 (n=30) to 0.700 (n=60) is itself evidence that the n=30 number was optimistic; the n=60 number is more reliable but still not the full set.
  • Same-task bias. The evaluator deterministically picks the first N tasks per split (IDs 1, 3, 5, …, 39 in the n=60 run), not a random subset. Our sample may be systematically easier or harder than the full set.
  • Two levers changed at once. Our run swapped the model (Gemini 2.5 Flash → Gemini 3.5 Flash) and added the expanded system-prompt (policy-precondition, preference-lookup, hallucination-guard rules). The relative contribution of each is un-ablated.
  • Pass@3 = 0.933. Only 4 of 60 tasks now fail in every trial (was 8 in the previous run; was 0 at n=30). Remaining systematic gaps: hallucination_33, _37, disambiguation_31 — plus one regression (disambiguation_9).
  • The headline numbers are optimistic (task-selection effect). A controlled run on 12 PREVIOUSLY-UNSEEN tasks scored ~0.33 Avg Pass^3 vs 0.80 on the always-used first-20 set. The held-out reliability is much lower; treat every "ours" row above as an upper bound that partly reflects which tasks were repeatedly measured. See the controlled experiment panel.
  • Local measurement, not official. Final ranking is produced by the organizers on a hidden test set on July 19, 2026. The numbers above are development validation only — useful for directional comparison, not for any external claim.
